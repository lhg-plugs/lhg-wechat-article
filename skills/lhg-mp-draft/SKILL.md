# lhg-mp-draft：公众号初稿写作方法论

> 目标：初稿要"顺"——读者能一口气读完，读完记得住 1 个观点、1 个金句、1 个行动点。
> 核心纪律：**按大纲写，不许自由发挥加模块；段落 ≤ 150 字，超了就拆。**

## 1. 何时使用

- 大纲已确认（用户说了"确认"或大纲评审清单全过）→ 用本 skill 写初稿
- 初稿某模块卡壳 → 回看本 skill 第 4 节的模块展开公式
- 改写阶段（rubric）→ 本 skill 的语言规范依然适用

## 2. 输入与输出

**输入**：确认过的大纲（含每模块论点/论据/金句/字数）。

**输出**：完整初稿 Markdown：frontmatter（标题/摘要/日期）+ 正文。文件名 `drafts/<日期>-<选题>-v1.md`。

## 3. 开头钩子：前 150 字的三种写法

大纲只定了钩子类型，这里是具体写法。无论哪种，**第 1 段 ≤ 80 字，第 3 段结束前必须进正题**。

**写法 A：悬念式（结果前置）**

```
第 23 天，我靠 AI 副业赚了 470 块。

不是 47000，是 470。但这是我 30 天里第一次觉得：
这事，成了。

前 22 天发生了什么？先说第 7 天——我颗粒无收。
```

要点：数字具体（470 不是"几百"）、情绪真实（"觉得成了"比"成功了"可信）、3 段内转场（"先说第 7 天"）。

**写法 B：反常识式（立靶子）**

```
学 prompt，是浪费时间。

过去 30 天，我测试了 27 个 AI 工具，结论很扎心：
用不好 AI 的人，缺的从来不是技巧，是不会"把活儿拆小"。
```

要点：第一句就是论点（不许铺垫）、第二句给证据（27 个工具/30 天）、第三句亮出真正的观点。

**写法 C：痛点共鸣式（点名道姓）**

```
你的收藏夹里，是不是也躺着 100 篇"AI 搞钱"教程？

收藏的时候热血沸腾，看完……还是一篇都没动手。
我也是。直到第 7 天，我逼自己接了第一个 120 块的单子。
```

要点：用"你"开头（第二人称拉近距离）、场景具体（收藏夹 100 篇）、快速转到"我"的行动（不贩卖焦虑，给出路）。

## 4. 模块展开公式：论点 → 论据 → 金句

每个模块 300~600 字，固定三段式（不是八股，是读者的认知节奏）：

**第一段：亮论点（50~80 字）**
开门见山，一句话说清这个模块的结论。不许绕。

```
副业的第一单，靠的不是技术，是敢报价。
```

**第二段起：摆论据（200~400 字）**
论据分三种，优先级：亲历细节 > 对话实录/截图描述 > 公开数据。

- 亲历细节要有"五感"：时间、地点、数字、动作。`第 7 天晚上 11 点，我在群里发出第一句报价："这个需求 200 块，接吗？"`——比"后来我接到了第一单"好 10 倍。
- 对话实录直接引用，用引用格式：`对方回："120 吧，行就行。"我盯着屏幕 3 分钟，回了个"行"。`
- 公开数据必须带来源：`（数据来源：艾瑞咨询《2026 自由职业报告》，待核实请替换）`。

**结尾：出金句（单独成段，1 句）**
金句 = 观点压缩成 20 字内的短句，能截图、能转发。

```
> 副业的第一课不是技能，是脸皮。
```

生产金句的 3 个套路：① 对比反转（"不是 A，是 B"）；② 数字具象（"重要 100 倍"）；③ 身份代入（"打工人的深夜"）。每模块至少 1 个，全文 3~5 个。

## 5. 段落节奏：手机阅读的铁律

- **一段 ≤ 150 字**：手机屏幕上超过 5 行就是"文字墙"，读者直接滑走。超了就拆，拆的原则是"一句一层意思"。
- **每 300 字一个呼吸点**：小标题、引用块、金句、分割线，四选一。让读者手指有地方停。
- **短句优先**：能用 10 个字说清，不用 20 个字。把"的"字句拆开：`AI 工具的使用技巧的掌握程度` → `你对 AI 工具的上手程度`。
- **禁用"首先、其次、最后"**：这是论文腔，不是人话。用"第一步"都比"首先"强；更好的办法是直接用小标题序号，连接词全部删掉。

## 6. 口语化表达：说人话检查清单

写完每模块，逐项检查：

- [ ] 有没有"的地得"混用、"的"字堆砌（自查脚本会抓一部分，人工再过一遍）
- [ ] 有没有"笔者、本文、综上所述"（出现就删，换成"我"）
- [ ] 有没有正确的废话（"机会总是留给有准备的人"——删了不影响任何信息量的句子，全删）
- [ ] 有没有具体数字（"很多"→"73%"、"很快"→"3 天"、"不少人"→"问我的 5 个人里有 4 个"）
- [ ] 有没有"你"（全文"你"出现 < 5 次，说明在自说自话，加第二人称互动句）

**朗读测试**：写完大声读一遍，凡是读着拗口、需要换气两次才读完的句子，重写。这是成本最低的质检。

## 7. 过渡句：模块之间不断裂

每个模块开头 1~2 句承上启下，三种接法：

1. **时间承接**：`熬过前 7 天的颗粒无收，第 15 天，我踩了第一个大坑。`
2. **问题承接**：`知道了"敢报价"，下一个问题来了：活儿接到了，交付怎么办？`
3. **观点承接**：`报价解决的是"有没有单"，但真正决定你能走多远的，是交付。`

大纲里已有过渡逻辑说明，这里是把它写成具体的句子。不许出现"下面我们来讲第二点"这种主持人串场词。

## 8. 收尾：两种写法的具体操作

**观点升华式**：回扣开头钩子，形成闭环。开头讲了 470 块，收尾就回应 470 块意味着什么。

```
30 天，470 块的最高单日收入。
钱不多，但它证明了一件事：普通人缺的从来不是机会，
是把"收藏夹"变成"备忘录"的行动力。
```

**行动点式**：给一个"今晚就能做"的具体动作，越小越好。

```
今晚就做一件事：
打开备忘录，写下 3 个你能卖的技能。不用完美，写下来就行。
明天的事，明天再说。
```

收尾之后加一句文末引导（1 句，不多）：`觉得有用，转发给那个总说"想搞副业"的朋友。`

## 9. 初稿的完成标准

- [ ] 全文 2500~3500 字（按大纲字数分配表，偏差 ≤ 15%）
- [ ] 开头 150 字内出现钩子，类型与大纲一致
- [ ] 每模块：论点句 + 论据（含来源标注）+ 金句（单独成段）
- [ ] 段落全部 ≤ 150 字；每 300 字有一个呼吸点
- [ ] "首先/其次/最后/综上所述"出现 0 次（自查脚本 MP-AI 类规则会验证）
- [ ] 全文"你"≥ 5 次；具体数字 ≥ 10 处
- [ ] 朗读测试通过（无拗口长句）

## 10. 反模式

- ❌ 开头自我介绍 300 字——读者不关心你是谁，只关心"这篇对我有什么用"
- ❌ 论据只有观点没有细节——"要敢报价"是观点，"第 7 天晚上 11 点发出第一句报价"才是论据
- ❌ 金句硬拗——不是每段都要金句，没有就别写，硬拗的金句比没有更尴尬
- ❌ 一段 400 字的文字墙——手机阅读直接劝退，拆
- ❌ 正确的废话凑字数——"坚持就是胜利"删掉，字数不够说明论据不够，回去补料

## 11. 自检与反馈

写完初稿自问：

1. 大纲里的每模块五件套都落实了吗？→ 有没有自由发挥加模块/删金句？
2. 完成标准 7 项全过了吗？→ 数字项（字数/段落/计数）用自查脚本验证一遍。
3. 朗读测试做了吗？→ 没读出声不算做。

标准冒烟用例：按本 skill 给的大纲写 1 个模块（500 字），检查段落长度、钩子、金句格式。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-wechat-article/issues，正文写清"输入 → 错误输出 → 期望输出"。
